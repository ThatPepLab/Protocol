# That PeP Lab Protocol Guide

Static GitHub Pages guide covering all 105 current TPLPrice product names through 104 distinct protocol pages (VIP and Vasoactive Intestinal Peptide share one page). The live page checks the TPLPrice repository every five minutes and retains a built-in snapshot if GitHub cannot be reached.

Concise protocol records compare recovered TPL material with PeptideDosages, Peptides Wiki, published research where available, and repeated community practice. Products without a dependable general protocol, products with ambiguous blend strengths, prescription-only products, topical materials, and supplies are reference-only and do not show syringe calculations.

Protocol content is for research and educational planning and is not medical advice.
